# Factures Balimmo

Portail de dépôt et de validation des factures des entreprises pour les chantiers Balimmo.

- `web/` : le site (statique)
- `supabase/schema.sql` : base de données et règles d'accès
- `supabase/functions/api/index.ts` : fonction serveur (mails, invitations, traduction)

Voir `GUIDE-INSTALLATION.md`.
